# AI Passport Badge

基于 ESP32-C3 的电子工牌固件，通过设备热点和本地网页配置内容，无需安装 App 或连接互联网。

## 功能

- 显示照片、姓名和个人简介，照片支持方形、圆角和圆形。
- 保存最多三张 240×320 个性化图片，支持切换、覆盖和清空槽位。
- 网页支持图片裁剪、拖动、缩放和旋转。
- 支持屏幕亮度、自动息屏和电量显示。
- 工牌和个性化图片均采用事务保存，写入失败时保留原数据。

## 使用

1. 长按“确认”进入设置并开启“Wi-Fi 热点”。
2. 手机连接 `AI-Passport-XXXX`。
3. 使用 Safari 或 Chrome 打开 `http://192.168.4.1/`。
4. 配置工牌或个性化图片；完成后在设备上按任意键关闭热点。

业务页面长按“上/下”切换工牌与个性化页面，个性化页面短按“上/下”切换已有图片。热点为无密码开放网络，请仅在近距离配置时临时开启。

## 构建

```sh
pio run
pio run -t upload
```

固件位于 `.pio/build/ai_passport_badge/firmware.bin`。请使用普通上传流程，不要全片擦除或将应用镜像直接写入 `0x0`，以免覆盖设备设置和用户数据。

## 测试

```sh
pio test -e native
node --test test/web/badge_web.test.js
```

自动化测试不能替代屏幕、按键和手机浏览器的真机测试。
