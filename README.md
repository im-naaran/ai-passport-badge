# AI Passport 工牌展示固件

本仓库构建 AI Passport 硬件的独立工牌/展示固件。固件包含全屏工牌、预留的个性化模块、显示设置和按需开启的 Wi-Fi 配置网页。消息、音乐、BLE、ANCS 与 AMS 属于其他固件，不会在本工程中编译或链接。

## 功能范围

- 启动后直接进入无公共顶部栏的全屏工牌，显示内置默认资料或最近一份有效用户资料。
- 工牌资料包含 200×200 照片、姓名和一条可选自定义语句。语句最多 96 个 UTF-8 字节，在设备上最多显示两行。
- 个性化模块当前没有内容，长按上/下会保持在工牌页，不会进入空白页面；未来有内容后才参与业务页切换。
- 设置页包含 Wi-Fi 热点、自动息屏、屏幕亮度和返回，并在列表顶部显示只读电量；电量不可用时显示 `--%`。
- 只有从设备设置页主动开启后，才会在 `http://192.168.4.1/` 提供离线配置网页。照片裁剪、旋转、形状遮罩和 RGB565 转换都在浏览器中完成，设备只接收最终资料。
- 工牌资料使用双槽事务保存；上传或 Flash 写入失败时继续使用上一份完整资料。旧 schema 1 的“姓名+照片”记录可继续读取，自定义语句按空处理。

目标硬件为 ESP32-C3、8 MB Flash、无 PSRAM、240×320 ST7789 屏幕、ADC 三按键和 CW2017 电量计。

## 按键操作

在业务页：

- 长按“上”：切换到前一个有内容的业务页。
- 长按“下”：切换到后一个有内容的业务页。
- 长按“确认”：进入设置。
- 短按不会修改工牌资料。

当前个性化模块没有内容，因此长按上/下不会离开工牌。设置不加入业务页循环。

在设置中，使用“上/下”选择项目或数值，使用“确认”进入或保存；顶部电量是只读状态，不占用光标行。选择“返回”会回到进入设置前的有效业务页。进入专用 Wi-Fi 页面后，任意有效按键手势都会退出页面并请求关闭热点；如果正在写入资料，底层会等待事务到达安全边界后再关闭。

## 使用 Wi-Fi 配置工牌

1. 长按“确认”进入设置，选择“Wi-Fi 热点”并确认。
2. 手机连接 `AI-Passport-XXXX`。
3. 使用 Safari 或 Chrome 打开 `http://192.168.4.1/`。
4. 选择并裁剪照片，填写姓名和可选自定义语句。
5. 选择方形、圆角或圆形照片效果，然后保存。
6. 保存成功后热点仍会保持开启，可以继续修改；在设备 Wi-Fi 页面按任意键即可退出并关闭热点。

照片形状由网页直接烘焙到 200×200 RGB565 像素中，设备不另外保存形状字段。圆角使用固定 24 px 半径；网页预览的遮罩外区域透明，上传时会合成到工牌页背景色，使设备上呈现透明效果。RGB565 本身不保存 Alpha 通道。读取已经保存的圆形或圆角照片时，网页无法恢复此前被遮罩丢弃的原始角落；需要恢复完整方形照片时，请重新选择原图。

> 安全提示：该热点是无密码开放网络，不提供认证、应用层保密或互联网服务。只应在配置工牌时短暂开启，并在设备附近操作，完成后立即关闭。不要在不可信的公共环境中提交敏感照片、姓名或自定义语句。

## 构建与烧录

仅需安装 PlatformIO Core，并确保 `pio` 可以从命令行调用。普通构建：

```sh
pio run
```

生成的应用镜像位于 `.pio/build/ai_passport_badge/firmware.bin`。

连接设备后直接构建并烧录：

```sh
pio run -t upload
```

串口无法自动识别时指定端口：

```sh
pio run -t upload --upload-port <device-port>
```

PlatformIO 会按 `partitions.csv` 分段写入 Bootloader、分区表和应用。普通上传不会写入 NVS、`badge_data@0x310000/0x40000` 或 `cardid@0x356000/0x4000`。禁止执行全片擦除，也不要把应用镜像直接写到 `0x0`。

当前自动化覆盖 native 核心逻辑、Web 纯逻辑和目标构建；它不能证明 LCD 布局、实体按键、手机浏览器、断电恢复、跨固件资料保留或功耗。真机结果应单独记录在 [本次功能验收矩阵](specs/20260927_badge_personalization_ui_enhancement/acceptance.md)。

## 可选本地测试

硬件无关的核心逻辑保留了 C/Unity 测试，可按需运行：

```sh
pio test -e native
```

离线配置网页使用 Node.js 内置测试工具，不需要安装 npm 依赖：

```sh
node --test test/web/badge_web.test.js
```

`tools/native_sources.py` 仅用于让 PlatformIO 为 native 测试注册白名单源码，由 PlatformIO 自行执行；普通固件构建和烧录不调用它，也不需要 Node.js。
