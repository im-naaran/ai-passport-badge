# 需求规格说明书

> 状态：已确认

## 背景与目标

当前导航把“工牌”和“个性化”建模为两个业务模式：长按上/下在两个模式间切换，进入个性化模式后再短按上/下切换最多三张个性化图片。

本次调整要拍平这两层导航。工牌在导航体验上视为第一张展示内容，已占用的个性化图片槽位分别作为后续展示内容。用户短按上/下即可直接在“工牌、个性化1、个性化2、个性化3”之间循环，不再先切换模式、再切换个性化图片。

“工牌视为一张图片”仅表示统一展示导航模型；工牌仍使用现有资料、布局和 `badge_data`，个性化图片仍使用独立槽位和 `custom_data`，本次不合并两者的数据格式或配置入口。

## 功能需求

### R-01：拍平展示导航序列

- 展示导航应形成一个扁平序列，固定以工牌为第一项，后续按槽位编号升序加入所有已占用的个性化图片。
- 每次冷启动或重启均应默认显示工牌；不得因为存在个性化图片、上次停留位置或刚完成上传而自动进入个性化项。
- 三个个性化槽位均已占用时，完整顺序为：`工牌 → 个性化1 → 个性化2 → 个性化3 → 工牌`。
- 存在空槽位时必须跳过空槽。例如仅槽位 1、3 有内容时，顺序为：`工牌 → 个性化1 → 个性化3 → 工牌`。
- 工牌始终可用，个性化图片是否进入序列仍以对应槽位当前是否存在有效内容为准。
- 导航层可以统一表示展示项，但不得因此合并工牌和个性化图片的持久化 schema、Flash 分区或配置 API。

### R-02：短按上/下直接切换展示内容

- 亮屏且处于展示页面时，短按下应移动到扁平序列的后一项，到达末项后循环回工牌。
- 亮屏且处于展示页面时，短按上应移动到扁平序列的前一项，在工牌处继续向前时循环到最后一个有效个性化项。
- 没有任何个性化图片时，工牌是唯一展示项；短按上/下均为无视觉变化的 no-op，不得重复执行页面离开和进入生命周期。
- 每次有效切换只改变一个展示项，并请求一次渲染；不得出现一次短按跨过多个有效项或重复切换。
- 短按确认在所有展示项上保持现有实际行为，即不执行操作。

### R-03：取消长按上/下切换模式

- 长按上/下不再切换工牌或个性化内容。
- 长按上/下不应改变当前展示项、个性化槽位、设置状态或持久化数据。
- 长按释放后不得追加短按切换；继续复用底层现有的长短按互斥保证。
- 本次不改变 50 ms 短按阈值和 800 ms 长按阈值。

### R-04：设置入口和内部操作保持不变

- 在任一展示项上长按确认仍进入设置。
- 进入设置后，短按上/下继续移动设置栏目或编辑选项。
- 设置内短按确认继续执行进入栏目、保存设置、返回列表或现有页面定义的确认操作。
- 设置页不得因展示导航改为短按而被短按上/下意外退出。
- 从设置返回后，应恢复进入设置前的展示项；若对应个性化槽位在设置期间失效，则安全回退到工牌。

### R-05：动态响应个性化槽位变化

- 新上传个性化图片成功后，对应槽位应立即加入展示序列，无需重启；当前展示项保持不变。
- 清空非当前个性化槽位后，该槽位应立即从展示序列移除，当前展示项保持不变。
- 清空当前正在显示的个性化槽位后，应安全回退到工牌，不得继续引用已经失效的图片。
- 清空全部个性化槽位后，展示序列只保留工牌。
- 槽位覆盖成功后继续停留在该个性化展示项并显示新内容；覆盖失败时继续显示上一份有效内容。
- 重启后根据已持久化的槽位占用状态重新构造相同的扁平序列。

### R-06：保留高优先级输入边界

- 屏幕关闭时，第一次按键手势仍只负责唤醒屏幕，不得同时切换展示项或操作设置。
- 热点配置专页激活时，任意按键手势仍优先关闭热点并回到设置列表，不得先执行展示切换。
- 无效按键、空指针或异常槽位状态不得造成越界、死循环或错误生命周期调用。

## 非功能需求

### NFR-01：最小影响面

- 优先重构现有导航/展示项状态，不修改按键 BSP、ADC 电压窗口或手势阈值。
- 工牌渲染继续复用 `badge_mode`，个性化渲染继续复用 `custom_mode`/`custom_view` 的既有图片展示能力。
- 不修改工牌资料、个性化图片存储、设置持久化、Wi-Fi/HTTP、分区表或网页功能。
- 不在 `app_main`、BSP 或应用控制器中散落硬编码的模式 ID 或槽位分支；展示序列规则应集中在导航或相邻的展示状态层。

### NFR-02：一致性与可测试性

- 上/下方向、循环顺序和空槽跳过必须由同一套规则产生，避免工牌与个性化项各自维护不一致的切换逻辑。
- native 测试应覆盖：0/1/2/3 个性化图片、稀疏槽位、上下双向循环、唯一工牌 no-op、短按确认 no-op、长按上/下 no-op、长按确认进入设置。
- 动态更新测试应覆盖：上传加入序列、清空非当前项、清空当前项回退工牌、覆盖保持当前项和重启重建序列。
- 集成测试应覆盖：设置进入/返回、息屏首次手势只唤醒、热点页任意手势只退出热点、有效切换请求渲染。
- 现有存储、HTTP、Web 和个性化图片测试必须保留；不能以删除局部切图测试之外的有效覆盖来适配新导航。
- 目标构建仅作为编译和链接兜底；LCD、实体按键顺序和真实长短按手感单独人工验收。

## 验收标准

1. 冷启动或重启始终先显示工牌；三槽均有图片时，只有用户短按后才按 `工牌 → 个性化1 → 个性化2 → 个性化3 → 工牌` 循环，短按上按相反方向循环。
2. 个性化槽位部分为空时，上/下切换始终跳过空槽；三槽均为空时，短按上/下保持工牌且不产生页面生命周期抖动。
3. 工牌保持现有资料化布局，个性化项保持 240×320 全屏图片显示；导航拍平不会改变两者的数据或视觉格式。
4. 长按上/下不再切换展示项，释放后也不会补发短按；短按确认在展示页保持 no-op。
5. 任一展示项长按确认均可进入设置；设置内上/下/确认行为不变，退出后返回原展示项。
6. 新上传图片无需重启即可进入序列；清空非当前项不改变当前画面；清空当前项立即安全回退工牌。
7. 息屏首次按键只唤醒；热点专页任意按键只退出热点；两者均不叠加展示切换。
8. 聚焦 native 测试、现有全量 native 回归和目标构建完成；真机 LCD/按键结果与自动化证据分开记录。

## 范围外内容

- 不把工牌渲染为 240×320 个性化 RGB565 图片，也不把工牌资料迁移到 `custom_data`。
- 不合并工牌配置和个性化图片配置的网页入口、HTTP API 或持久化记录。
- 不调整按键硬件、ADC 分压、去抖、短按和长按时间阈值。
- 不新增双击、组合键、自动轮播、转场动画或展示项标题覆盖层。
- 不改变个性化图片数量、槽位编号、图片格式或事务存储机制。
- 不调整设置项目、设置页面视觉、热点配置流程或 Flash 分区。

## 非阻塞实现参数

- 统一展示序列的逻辑索引可以与现有模式 ID、个性化物理槽位编号分离；实现需集中转换并测试。
- 个性化展示项的用户名称采用“个性化1～3”，数字对应网页和存储中的槽位 1～3。
- 上传新槽位时不自动跳转；清空当前槽位时统一回退工牌，以避免失效指针和不确定的相邻项选择。
- 设置返回目标应记录为稳定的展示项身份，而不是易随空槽增删变化的数组下标。
